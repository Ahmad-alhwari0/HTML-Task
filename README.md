# HTML Task

## What is this task?
This repository contains 3 HTML pages built using HTML only
(no CSS at all). The pages are:
1. Form page– An application form with text fields, date, 
   dropdown, radio buttons, checkboxes, and buttons.
2. List page – Three different lists: a descending numbered 
   ranking list, a nested bullet list, and a nested numbered/bullet list.
3. Table page – A table demonstrating colspan and rowspan.

All layouts are built purely with native HTML elements/attributes, 
without any external or inline CSS styling.
